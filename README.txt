BSTAR SLEEPWEAR — GitHub Pages-ready landing page

FILES
- index.html       Main page
- style.css        Styling and responsive layout
- script.js        Language toggle, search/filter, shopping bag and WhatsApp order
- favicon.ico      Browser icon
- assets/bstar-logo.png  Your uploaded BStar logo
- assets/favicon.png     PNG favicon

PUBLISH TO GITHUB PAGES
1. Extract this ZIP on your computer.
2. Open your GitHub repository and upload the CONTENTS of this folder (not the ZIP itself).
3. Make sure index.html is in the repository root.
4. Commit the files.
5. Go to Settings > Pages and publish from your chosen branch/root.

NOTES
- Product photography is hotlinked from Unsplash as temporary inspiration. Replace these with your own product photos before selling, and check each photo's license/terms.
- Product names/prices are sample data. Edit them in index.html and script.js.

- The newsletter is demo-only and is not connected to an email marketing service.
- Change hello@bstar.example in index.html to your real store email.
